We are looking for a motivated Frontend Developer to join our growing team. You will build responsive, accessible and user-friendly web experiences while working with designers and backend developers.

Job Description

As a Frontend Developer, you will turn design concepts into high-quality interfaces. You should have a strong understanding of modern web technologies and a passion for clean user experiences.

Responsibilities

  • Develop responsive websites using HTML, CSS and JavaScript.
  • Build reusable UI components and maintain clean code.
  • Collaborate with UI/UX designers and backend developers.
  • Test websites across different browsers and devices.
  • Identify and fix interface bugs and performance issues.

Requirements

  • Good knowledge of HTML5, CSS3 and JavaScript.
  • Understanding of React is a plus.
  • Basic knowledge of Git and GitHub.
  • Strong problem-solving and communication skills.
  • Portfolio or relevant projects are preferred.
